# 缓冲垫项目现场配置简明说明

给现场操作员使用，按顺序配置，不要跳步。

## 一、配置顺序

```text
1. 寿命
2. 位置
3. 设备
4. 三菱 PLC 通信端口
5. PLC 地址
6. 测试
```

一句话：先配位置和设备，再让三菱 PLC 打开 3301 通信端口，然后配 PLC 地址，最后去运行页面扫码测试。

## 二、配置前准备信息

| 需要的信息 | 找谁确认 | 示例 |
| --- | --- | --- |
| 产线编号 | 现场负责人 | `1线`、`2线` |
| 扫码器位置 | 现场负责人 | `上`、`下`、`间层1`、`间层2` |
| 每台设备 IP 和端口 | IT/电气人员 | 扫码器 `192.0.2.10:15000` |
| PLC 类型和型号 | 电气人员 | 三菱 R 系列、汇川 AM/AC 系列 |
| PLC 点位表 | PLC 工程师 | `D6600` 对应扫码成功 |

没有 PLC 点位表时，不要凭感觉填写 PLC 地址。地址虽然能保存，但 PLC 可能收不到正确信号。

## 三、第一步：配置缓冲垫寿命

菜单：`设置 -> 缓冲垫寿命`

| 要配什么 | 怎么填 |
| --- | --- |
| 最大使用次数 | 按现场要求填写，默认 `500` |

说明：缓冲垫扫码次数达到最大次数后，系统会提示超过寿命，并通知 PLC。

## 四、第二步：配置设备安装位置

菜单：`设置 -> 设备安装位置`

| 字段 | 怎么填 | 示例 |
| --- | --- | --- |
| 位置名称 | 现场一眼能看懂的位置 | `上`、`下`、`间层1`、`间层2`、`PLC柜` |
| 排序号 | 数字越小越靠前 | `1`、`2`、`3`、`4` |

建议先把扫码器位置全部配好，再去配置设备。

## 五、第三步：配置设备信息

菜单：`设置 -> 设备信息`

| 字段 | 怎么填 | 示例 |
| --- | --- | --- |
| 设备类型 | 扫码器、三菱PLC、汇川PLC 三选一 | `扫码器` |
| 设备名称 | 能看出来是哪台设备 | `1线-上扫码器` |
| IP | 设备实际地址 | `192.0.2.10` |
| 端口 | 扫码器常见 `15000`；三菱 R 系列默认 `3301`；汇川 AM/AC 常见 `502` | `15000` |
| 产线 | 和对应 PLC 保持一致 | `1` |
| 安装位置 | 从第二步配好的位置里选 | `上` |

注意：同一组扫码器和 PLC 的产线必须一致，否则配置 PLC 地址时会报错。

三菱 PLC R 系列的设备信息建议这样填：

| 字段 | 示例 |
| --- | --- |
| 设备类型 | `三菱PLC` |
| 设备名称 | `上缓冲垫PLC` |
| IP | `192.0.2.16` |
| 端口 | `3301` |
| 产线 | `1` |
| 安装位置 | `上缓冲垫` 或 `PLC柜` |

这里的 `3301` 是后端连接三菱 PLC 的 MC/SLMP 通信端口，不是心跳地址，也不是 `D6600` 这种寄存器地址。

## 六、第四步：配置三菱 PLC R 系列通信端口

三菱 R 系列 PLC 必须在 GX Works3 里打开 MC/SLMP 通信端口。本项目默认使用 `3301` 端口，并且必须使用 `TCP`。

应该这样配：

| 项 | 应该怎么填 |
| --- | --- |
| 型号 | `SLMP连接设备` |
| 通信手段 | `SLMP` |
| 协议 | `TCP`，不要选 `UDP` |
| 可编程控制器 IP地址 | PLC 自己的 IP，例如 `192.0.2.16` |
| 可编程控制器 端口号 | `3301` |

关键操作步骤：

1. 在以太网配置界面新增或选中 `SLMP连接设备` 这一行。
2. `协议` 下拉选择 `TCP`，不要选 `UDP`。
3. `IP地址` 填 PLC 自己的 IP，例如 `192.0.2.16`。
4. `端口号` 填 `3301`。
5. 点上方菜单里的“反映设置并关闭”，不要点“取消设置并关闭”。
6. 回到参数页面后点“应用”。
7. 执行“在线 -> 写入至可编程控制器”，把参数写入 PLC。
8. 写入后需要 PLC 复位或断电重启，否则端口可能不会真正生效。
9. 重启后在后端电脑上测试：

```powershell
Test-NetConnection 192.0.2.16 -Port 3301
```

如果 `TcpTestSucceeded` 是 `True`，说明端口已打开。
如果后端日志出现 `Connection refused`，通常说明 PLC 的 `3301` TCP 端口还没真正打开。

## 七、第五步：配置 PLC 地址

菜单：`设置 -> PLC地址`

这一步是告诉系统：扫码器出现某种结果时，要通知哪台 PLC 的哪个寄存器。

先看 PLC 类型，再决定地址格式：

| PLC 类型 | 地址格式 | 示例 | 不要填 |
| --- | --- | --- | --- |
| 三菱 R 系列 | `D` + 数字 | `D6600`、`D6601`、`D271` | `MW10000` |
| 汇川 AM/AC 系列 | `MW` + 数字 | `MW10000`、`MW9400` | `D6600` |

常用范围：三菱 R 系列常用 `D0` 到 `D12287`；汇川 AM/AC 系列常用 `MW0` 到 `MW65535`。最终以 PLC 工程师给的点位表为准。

常用操作类型：

| 操作类型 | 系统做什么 |
| --- | --- |
| 扫码失败 | 扫码器返回 `NoRead`，系统向 PLC 写入 `1` |
| 扫码成功 | 读到二维码且未超过寿命，系统向 PLC 写入 `1` |
| 扫码超过最大次数 | 读到二维码但次数超过寿命，系统向 PLC 写入 `1` |
| 重新扫码成功 | 手动扫码或重扫成功，系统向 PLC 写入 `1` |
| 重新扫码超过最大次数 | 手动扫码或重扫超过寿命，系统向 PLC 写入 `1` |
| 心跳 | 系统定时向 PLC 写入 `0`，一台 PLC 建议只配一条 |
| 开口数回读 | 系统从 PLC 读取 16 位整数并保存到记录中 |

填写示例：

| PLC 型号 | 扫码失败 | 扫码成功 | 超过次数 | 开口数回读 |
| --- | --- | --- | --- | --- |
| 三菱 R 系列 | `D6600` | `D6602` | `D6601` | `D6606` |
| 汇川 AM/AC 系列 | `MW10000` | `MW10002` | `MW10001` | `MW10006` |

同一个扫码器的同一种操作类型只能配置一个地址。同一个扫码器只能对应一台 PLC。

## 八、扫码器输出格式确认

扫码器需要把二维码数据发给后端。系统支持下面几种格式：

| 场景 | 扫码器应该发送的内容 |
| --- | --- |
| 扫到二维码 | `[TPL_STX]BP-001[TPL_ETX]` |
| 没有读到码 | `NoRead` |
| 心跳 | `HeartBeat` |

注意：`NoRead` 大小写要完全一致，不要写成 `noread`、`NO_READ` 或中文。

## 九、最后测试

| 顺序 | 要做什么 | 看什么结果 |
| --- | --- | --- |
| 1 | 打开运行页面，刷新设备状态 | 扫码器和 PLC 状态正常 |
| 2 | 扫一张测试二维码 | 缓冲垫列表新增或次数增加 |
| 3 | 查看扫码记录 | 有成功、失败或超过次数日志 |
| 4 | 让电气人员看 PLC 对应 D/MW 地址 | PLC 收到信号 |
| 5 | 测试 `NoRead` | 系统记录扫码失败，PLC 收到失败地址信号 |

## 十、上线前检查清单

```text
[ ] 缓冲垫最大使用次数已配置
[ ] 设备安装位置已建好，名称和现场一致
[ ] 每台扫码器都配置了设备信息
[ ] 每台 PLC 都配置了设备信息
[ ] 三菱 R 系列 PLC 已配置 SLMP / TCP / 3301
[ ] 三菱 R 系列 PLC 参数已写入并复位或断电重启
[ ] 同一组扫码器和 PLC 的产线一致
[ ] 三菱 R 系列地址用 D，汇川 AM/AC 系列地址用 MW
[ ] 每个扫码器已配置扫码成功、扫码失败、超过次数等 PLC 地址
[ ] 扫码器输出格式是 [TPL_STX]二维码[TPL_ETX]，失败输出 NoRead
[ ] 运行页面测试扫码成功，PLC 侧也收到信号
```

## 十一、运行页面怎么看

| 页面内容 | 现场人员怎么处理 |
| --- | --- |
| 设备状态为绿色 | 设备在线，可以正常操作 |
| 设备状态为红色 | 点“查看设备”，按页面显示的 IP、端口和错误检查设备 |
| 绿色运行消息 | 本次扫码、计数或 PLC 通知成功 |
| 黄色运行消息 | 缓冲垫可能已计数，但存在重复扫码、缺少地址等问题，先看处理建议 |
| 红色运行消息 | 达到寿命、计数失败或 PLC 不可用，需要立即处理 |
| 实时消息连接中断 | 页面会自动重连；长时间不恢复时检查后端服务和网线 |

注意：PLC 通知失败不等于缓冲垫没有计数。先在当前缓冲垫和列表中确认使用次数，再决定是否重扫，避免重复操作。运行页面显示最近20条操作，数据库默认保留最近30天。

如果某一项不确定，先停下来问 PLC 工程师或项目维护人员，不要随便修改 PLC 地址。
