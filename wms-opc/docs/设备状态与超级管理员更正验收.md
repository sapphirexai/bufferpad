## 后续网络证据（09:28）

针对用户提出的 192.0.2.21 ping 不通问题，在 149 的 ens192 使用 Python AF_PACKET 抓取独立 TCP 连接的报文，不经过应用和 HSL/Netty：

- 192.0.2.4:39221 → 192.0.2.21:15000：SYN。
- 约 13 ms 后收到 192.0.2.21:15000 → 192.0.2.4:39221：SYN-ACK。
- 本机回复 ACK，系统 connect() 成功，SO_ERROR=0。
- 随后同机 ping 三次，0 次响应、100% 丢包。
- 路由为 via 192.0.2.2 dev ens192；收到 SYN-ACK 的以太网源 MAC 为 00:a1:67:77:55:db。
