缓冲垫系统用户使用说明书

本说明书面向现场操作员、班组长和日常使用人员，帮助您快速了解缓冲垫扫码计数系统的页面用途、按钮功能、常见提示及标准操作流程。内容依据项目代码中的前端页面与后端业务规则整理，可直接作为日常使用参考。

适用范围 缓冲垫扫码、寿命查看、扫码记录查询、日志排查、导出与批量维护
主要页面 Running、Summary、Record、明细页、日志查询页

一、系统概览

系统能做什么

  • 接收扫码器上传的缓冲垫二维码，并自动登记使用次数。
  • 显示当前缓冲垫、当前位置、使用次数、剩余次数、设备连接状态。
  • 查询历史扫码记录、查看单个缓冲垫的明细记录、查看异常日志。
  • 支持导出选中数据，以及批量调整缓冲垫的使用寿命。

系统自动判定规则

  • 同一个缓冲垫在 2 小时内重复扫码，系统会视为无效扫码，不增加使用次数。
  • 达到最大使用次数后，系统会提示已到上限，并向 PLC 发送对应信号。
  • 扫码成功后，系统会尝试读取对应的开口数，并写入当前记录。
  • 运行页会通过后台推送实时刷新，不需要手动反复刷新页面。
建议把 Running 页作为现场主操作页面。Summary、Record、日志页更适合查询和复核，不建议代替运行页进行实时判断。

二、快速操作流程

  1. 进入系统后，先在运行页选择当前产线，确认 PLC状态 和 读码器状态 为绿色。
  2. 正常情况下等待扫码器自动上传二维码，系统会自动更新当前缓冲垫、位置、使用次数和列表数据。
  3. 如果扫码失败或现场需要补录，点击 手动输入，输入二维码后再点击 确定。
  4. 如需查看某个缓冲垫的详细扫码历史，在表格中找到该条数据后点击 明细。
  5. 如需批量修改寿命或导出数据，先勾选表格行，再使用 批量修改 或 导出。
  6. 如需排查失败原因或确认系统提醒，点击 日志查询 查看普通/异常日志。

三、颜色与状态说明

连接状态

绿色 设备连接正常、处于活跃状态。

红色闪烁 设备未连接或连接异常，需要检查网络、设备或后台服务。

使用次数颜色

绿色 使用次数仍处于安全范围内。

橙色 已接近寿命预警阈值。

红色背景/提示 已达到或超过使用上限，应及时处理。

缓冲垫位置使用 上、下、间层1、间层2 标识。运行页中不同位置会使用不同颜色区分，便于现场快速识别。

四、Running 运行页

运行页是系统的核心页面，负责现场实时监控和主要操作。左侧导航进入 Running 后，页面主要分为顶部状态区、当前缓冲垫信息区、操作区和数据表格区。

1. 顶部状态区

  • 产线选择：可在 1 到 5 号产线之间切换。切换后，设备状态、当前信息和表格数据会一起刷新。
  • PLC状态：显示当前产线 PLC 的连接情况。
  • 读码器状态：显示扫码器是否在线。

2. 当前缓冲垫信息区

缓冲垫编号输入框

  • 默认用于接收扫码结果，初始状态不可手动输入。
  • 点击 手动输入 后输入框启用，按钮文字变为 确定。
  • 输入二维码后，必须点击 确定 提交，回车键不会直接提交。

当前缓冲垫卡片

  • 当前缓冲垫：显示最近一次成功扫码或手动补录的二维码。
  • 位置：显示缓冲垫所在工位，如 上、下、间层1、间层2。
  • 使用次数：显示当前已计入的有效使用次数。
  • 剩余次数：按 使用寿命 - 使用次数 计算。

3. 运行页操作区

功能 作用 使用说明
搜索缓冲垫 按编号筛选表格 输入缓冲垫编号后点击搜索图标或直接按查询逻辑刷新列表。
阈值设置 设置接近寿命时的预警比例 点击编辑图标后可设置 0 到 1 之间的数值，例如 0.95 代表达到寿命的 95% 时预警。该设置保存在当前浏览器中。
日志查询 跳转到日志页 用于查询普通日志和异常日志，适合排查扫码失败、设备问题等情况。
批量修改 批量修改使用寿命 必须先勾选至少一条数据，否则系统会提示“请选择修改数据”。
导出 导出选中缓冲垫信息到 Excel 必须先勾选数据，否则系统会提示“请选择导出数据”。导出后浏览器会自动下载文件。

缓冲垫位置 当前扫码来源位置，优先显示明确的工位名称。

5. 运行页常用操作

手动补录二维码

  1. 点击 手动输入。
  2. 在输入框中输入二维码。
  3. 点击 确定。
  4. 系统提示成功后，当前缓冲垫和表格会自动刷新。

修改单条使用寿命

  1. 在目标数据行的 使用寿命 列点击编辑图标。
  2. 输入新的使用寿命值。
  3. 点击列内 确定。
  4. 系统提示“修改完成”后，列表自动刷新。
如果运行页提示“扫码失败，请手动输入”，说明扫码器未成功识别本次二维码，您可以按手动补录流程继续操作。

五、Summary 汇总页

汇总页主要用于快速浏览缓冲垫总体信息，适合作为辅助查询页面。该页面不提供编辑按钮，重点是看列表。

  • 页面字段包括：缓冲垫编号、缓冲垫位置、开口数、缓冲垫生产厂家、第一次使用时间、最后一次使用时间、当前使用次数、剩余次数。
  • 支持分页浏览，可切换每页条数和页码。
  • 若需要实时确认最新扫码结果或剩余寿命，建议以运行页显示为准。

六、Record 记录页

记录页用于查看历史扫码记录，适合按时间范围回溯现场操作。

1. 页面功能

  • 可选择开始时间和结束时间后点击 查询。
  • 表格显示字段为：缓冲垫编号、开口数、缓冲垫位置、扫码时间。
  • 支持分页浏览。

2. 使用场景

  • 确认某一时间段内是否发生过扫码。
  • 查看扫码发生的具体时间和位置。
  • 配合运行页或日志页核对现场作业记录。

七、缓冲垫明细页

明细页不在左侧导航中，需要从运行页表格中点击某条数据的 明细 进入。该页面用于查看单个缓冲垫的历史扫码明细。

  • 页面字段包括：缓冲垫编号、开口数、缓冲垫位置、扫码时间。
  • 默认按传入的缓冲垫编号查询。
  • 支持分页切换，便于查看较长的历史记录。

八、日志查询页

日志查询页用于查看系统运行日志，是排查异常最重要的辅助页面之一。该页面通常从运行页点击 日志查询 进入。

1. 可筛选条件

  • 缓冲垫编号：查询指定编号相关日志。
  • 日志类型：可选 普通 或 异常。
  • 日志内容：按日志文字模糊查询。
  • 创建时间：默认查询当天，并支持快捷选择 当天、最近三天、最近七天。

2. 表格字段说明

  • 日志类型：普通日志显示为普通文本；异常日志会显示警告图标和红色样式。
  • 缓冲垫编号：与该条日志相关的二维码。
  • 日志内容：系统生成的说明文字。
  • 创建时间：日志生成时间。

十、使用注意事项

  • 开始作业前，请先确认 PLC 和读码器状态为绿色，否则扫码结果可能无法正常入库。
  • 手动输入适用于补录场景，不建议代替正常扫码使用。
  • 批量修改和导出前必须先勾选数据。
  • 寿命预警阈值保存在当前浏览器本地，不同电脑或不同浏览器之间不会自动同步。
  • 如果某个缓冲垫短时间内重复扫码但次数没有增加，通常是因为系统启用了 2 小时有效间隔规则。
  • 如果网络异常或后台服务未启动，页面可能无法取到数据，此时应先检查网络、后台服务和设备连接。

十一、常见问题

1. 为什么扫码成功了，但使用次数没有增加？

系统存在 2 小时有效间隔规则。同一个缓冲垫在 2 小时内重复扫码，会被判定为无效扫码，因此不会增加使用次数。

2. 为什么批量修改按钮点了没有反应？

运行页中必须先勾选至少一条数据，未勾选时系统会提示“请选择修改数据”。

3. 为什么导出按钮不能直接导出？

导出功能只导出勾选的数据。请先勾选要导出的缓冲垫，再点击 导出。

4. 为什么设备状态显示红色或闪烁？

这通常表示 PLC 或读码器未连接、网络异常，或者后台服务未正常通讯。建议先检查设备供电、网络连通性及后台服务运行状态。

5. 扫码失败后应该怎么做？

先查看日志页是否有异常提示；如果现场需要继续作业，可在运行页点击 手动输入 进行补录。
