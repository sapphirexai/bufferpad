| 组件 | 导入分支 | 来源提交数 |
|---|---|---:|
| `bufferpad/` 前端 | `main` | 48 |

保留 304 条来源提交的作者、提交者、时间和父子关系，导入后另有合并和开源适配提交。项目从 GitHub 原有 MIT LICENSE 初始提交继续发展。

公开历史中移除了第三方安装包、构建制品、HSL JAR、运行日志、部署密钥及 IDE 元数据，并按规则排除 PDF。配置和文档中的现场地址、共享凭据及工作站路径已脱敏。历史中的示例值不能用于实际部署。

增加组件目录前缀及清理内容后，来源 commit SHA 发生变化。维护者保留了原始私有备份和旧、新编号映射。只修改了被移除内容的提交仍作为空提交保存，本次共有 5 条这样的结果。其他分支端点以 `archive/<组件>/<来源>/<原分支>` 保留；归档分支记录历史版本，不是推荐部署版本。

迁移核对了全部 304 条来源提交的元数据、父子关系及过滤后的历史文件树。新版本进一步改为部署者配置初始管理员密码，并默认关闭共享维护登录。这些改动位于导入历史之后的独立提交，不改写原有开发时间。

历史验收文档记录迁移前的工程活动，不能作为当前提交的测试结果；当前版本应按构建说明重新验证。迁移不包含原 GitLab 的 Issue、MR、流水线记录或附件。
