# BufferPad v0.1.1 — Source preview validation fix

This patch retains all [v0.1.0 capabilities](https://github.com/sapphirexai/bufferpad/releases/tag/v0.1.0) and fixes a validation issue found during the final fresh-clone audit.

## 修正

- PowerShell 语法检查器改为显式按 UTF-8 读取源码，避免 Windows PowerShell 5.1 将部分无 BOM 中文文件按本地编码误读。
- 检查器分别通过 Windows PowerShell 5.1 与 PowerShell 7 验证；说明语法通过不等于正式安装验收。
- 没有修改前端、后端或安装器业务源码；保留原 v0.1.0 标签。

## 获取与限制

```text
git clone --branch v0.1.1 https://github.com/sapphirexai/bufferpad.git
```

仍为源码预览版，不附带 HSL JAR、第三方安装包或应用成品。完整后端构建需要自行准备适用授权的 HslCommunication Java 3.4.0。

CI 覆盖前端测试与构建、仓库检查和 PowerShell 语法，不运行后端完整测试或正式安装。Windows PowerShell 5.1 直接执行部分无 BOM 中文安装脚本的兼容性仍需单独处理，当前脚本验证基线为 PowerShell 7。真实 PLC、现场数据库升级和生产服务安装未在本轮验收。

English: The syntax checker now reads UTF-8 explicitly and works under Windows PowerShell 5.1 and PowerShell 7. This does not certify installer execution under 5.1. No business components changed; source-only distribution and the external HSL prerequisite remain unchanged.
