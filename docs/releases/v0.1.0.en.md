# BufferPad v0.1.0 — Source preview

[简体中文](v0.1.0.md) · **English** · [All documentation](../README.en.md)

First public source preview of BufferPad, an industrial cushion lifecycle tracking and PLC integration system, for reading, evaluation, and deployment in an isolated test environment. This document translates the release record; it does not change the old tag or its original files.

## Included

- Barcode counting, duplicate handling, lifetime thresholds, history queries, and device diagnostics.
- Frontend, backend, and Windows installation/maintenance source combined with 304 source development commits.
- [Illustrated tour](../product-tour.en.md), [setup](../getting-started.en.md), contribution and security reporting guidance. These English links open current documentation; the [original tagged tour](https://github.com/sapphirexai/bufferpad/blob/v0.1.0/docs/product-tour.md) and [setup](https://github.com/sapphirexai/bufferpad/blob/v0.1.0/docs/getting-started.md) preserve release-time Chinese content.
- GitHub frontend test/build, repository, and PowerShell checks.
- Chinese/English README, bilingual roadmap, issue/PR templates, and protected-main maintenance.

## Obtain source and prerequisites

Use GitHub's autogenerated Source code archives or:

```text
git clone --branch v0.1.0 https://github.com/sapphirexai/bufferpad.git
```

This is not a ready-to-run installer. Prepare Java 17, the Node 18.19.0 compatible build environment, MySQL 8, and runtime packages. Obtain HslCommunication Java 3.4.0 and appropriate authorization separately; the backend cannot compile completely without it. No HSL, third-party installer, or compiled frontend/backend is attached. MIT covers project-owned source; third parties retain their terms.

## Validation and limits

Migration validation recorded 65 frontend and 152 backend tests, with local HSL for backend testing. See the [release-time CI scope](https://github.com/sapphirexai/bufferpad/blob/v0.1.0/docs/ci.md) (Chinese); public CI does not compile/test the complete backend.

This preview did not complete all-model physical PLC integration, production Windows installation, live MySQL upgrades, or browser E2E acceptance. Verify protocols, addresses, and writes in isolation before connecting actual equipment.
