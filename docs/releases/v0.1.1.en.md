# BufferPad v0.1.1 — Source preview validation fix

[简体中文](v0.1.1.md) · **English** · [All documentation](../README.en.md)

This patch retains [v0.1.0 capabilities](https://github.com/sapphirexai/bufferpad/releases/tag/v0.1.0) and fixes an issue found during fresh-clone validation. This translation does not modify existing tags or historical release assets.

## Fixes

- The PowerShell syntax checker reads UTF-8 explicitly, preventing Windows PowerShell 5.1 from misinterpreting some BOM-less Chinese files using its local encoding.
- The checker was verified under Windows PowerShell 5.1 and PowerShell 7; syntax success is distinct from actual installation acceptance.
- Frontend, backend, and installer business source did not change. The v0.1.0 tag was retained.

## Source and limitations

```text
git clone --branch v0.1.1 https://github.com/sapphirexai/bufferpad.git
```

This remains a source preview without HSL JARs, third-party installers, or application binaries. Full backend builds require a separately obtained, appropriately authorized HslCommunication Java 3.4.0 dependency.

CI covers frontend tests/build, repository checks, and PowerShell syntax, not full backend testing or actual installation. Direct execution of some BOM-less Chinese installer scripts under Windows PowerShell 5.1 still requires separate compatibility work; the script-validation baseline is PowerShell 7. Physical PLCs, live database upgrades, and production services were not accepted in this round.
