# BufferPad v0.1.0 — Source preview / 源码预览版

**简体中文** · [English](v0.1.0.en.md) · [文档目录](../README.md)

BufferPad 是面向制造现场的缓冲垫寿命追踪与 PLC 联动系统。这是首次开源源码预览发布，适合阅读、评估和在独立测试环境中部署。

## 本版内容

- 扫码计数、防重复处理、寿命阈值、记录查询及设备状态诊断。
- 前端、后端与 Windows 安装维护脚本合并，保留 304 条来源开发历史。
- [三图界面导览](https://github.com/sapphirexai/bufferpad/blob/v0.1.0/docs/product-tour.md)。
- [构建与部署说明](https://github.com/sapphirexai/bufferpad/blob/v0.1.0/docs/getting-started.md)、贡献指南及安全报告入口。
- GitHub Actions 自动执行前端测试与构建、仓库检查及 PowerShell 语法检查。
- 中英文 README、双语路线图、Issue/PR 模板和受保护的 main 维护流程。

## 获取与依赖

使用本 Release 的 GitHub 自动生成 Source code 下载，或克隆标签：

```text
git clone --branch v0.1.0 https://github.com/sapphirexai/bufferpad.git
```

源码不包含可直接安装的完整程序。请按说明准备 Java 17、Node 18.19.0 兼容构建环境、MySQL 8 和所需运行时。HslCommunication Java 3.4.0 需自行取得适用授权与 JAR；没有它，当前后端无法完整编译。

本 Release 不附带 HSL、第三方安装包或前后端成品。MIT 适用于项目自有代码，第三方组件遵守各自许可。

## 验证与限制

迁移验证曾通过前端 65 项、后端 152 项测试；后端使用本地 HSL。当前 CI 检查范围以[说明](https://github.com/sapphirexai/bufferpad/blob/v0.1.0/docs/ci.md)为准，不包含后端完整编译和测试。

本版为预览版，未完成真实 PLC 全型号联调、正式 Windows 安装、现场 MySQL 升级或浏览器 E2E 验收。连接真实设备前请在隔离环境核对协议、地址和写入行为。

## English summary

First public source preview of BufferPad, an industrial cushion lifecycle tracking system. Includes the Vue frontend, Java backend, Windows deployment scripts, illustrated documentation, and scoped CI. Obtain the licensed HSL 3.4.0 dependency separately before building the backend. Source archives are not ready-to-run installers; hardware and production deployment validation remain the deployer's responsibility.
